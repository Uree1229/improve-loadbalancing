# v24 추가 개선 비교

새 부팅 한 번에서 같은 v18 커널로 v18·v19·v23·v24 호스트 조건을 144회 비교했다. v24는 v23에 두 코어 등급의 최소 성능 하한 100%를 더했다.

| 지표 | v18 설정 | v19 설정 | v23 설정 | v24 설정 |
|---|---:|---:|---:|---:|
| 200ms 복구 지연 중앙값 | 2.691 ms | 2.294 ms | 1.915 ms | 1.980 ms |
| 835ms 복구 지연 중앙값 | 4.703 ms | 2.033 ms | 1.478 ms | 1.819 ms |
| 835ms 복구 지연 관측 최댓값 | 12.510 ms | 2.830 ms | 2.308 ms | 2.263 ms |
| pinned-256 VM CPU 시간 중앙값 | 13.492 s | 13.492 s | 9.875 s | 9.836 s |

기존 세 사용자 기준과 추가 19개 기준은 통과했지만, v23 대비 추가 개선 기준은 미달했다. 200ms 중앙값 0.1ms 감소, 835ms 최대 지연 0.25ms 감소, pinned CPU 시간 2% 감소 중 어느 기준도 충족하지 못했다.

835ms 중앙값은 v23보다 0.341ms 증가했다. pinned CPU 시간의 짝비교 중앙값 변화는 v23 대비 -0.395%였다. v24의 추가 채택과 재부팅 재현은 진행하지 않았다. 실제 CPU 주파수와 에너지 사용량은 측정하지 않았다.
