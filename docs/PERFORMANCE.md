# 성능 그래프의 출처와 해석

README 그래프는 저장소에 공개된 기존 실험의 요약값을 그린 것이다. 새 벤치마크를 실행하거나 개별 측정값을 생성하지 않았다. 공개된 성능 요약값이 없는 버전은 그래프에서 제외했으며, 모든 버전이 같은 환경에서 측정됐다고 가정하지 않는다.

## 비교 단위

| 그래프 | 입력 | 비교 범위 |
| --- | --- | --- |
| [커널 비교](images/kernel-comparison.svg) | [results.json](../experiments/fixed-host-kernel-ab-20261108/results.json) | v23 호스트 정책 고정, 원본과 v18 커널을 번갈아 5회 부팅, 정식 180회 |
| [호스트 정책 비교](images/host-policy-comparison.svg) | [v24 RESULTS.json](../versions/v24/RESULTS.json) | v18 커널 고정, 같은 새 부팅의 v18·v19·v23·v24 설정, 정식 144회 |
| [v22 재현 비교](images/v22-reproduction.svg) | [v22 RESULTS.md](../versions/v22/RESULTS.md) | v18 커널 고정, 각 부팅의 v18·v19·v22 설정, 108회씩 2부팅 |
| [v23 재현 비교](images/v23-reproduction.svg) | [v23 RESULTS.json](../versions/v23/RESULTS.json) | v18 커널 고정, 각 부팅의 v18·v19·v23 설정, 108회씩 2부팅 |

커널 비교의 복구 조건은 부팅당 각각 8회, 일반 작업 다섯 조건은 각각 4회다. v22도 부팅·설정별 복구 조건은 각각 8회, pinned-256은 4회다. v23·v24 그래프에는 공개 요약에서 확인되는 전체 정식 실행 횟수를 표시한다. 전체 실행 횟수가 각 막대의 표본수라는 뜻은 아니다.

v23에서 중단된 별도 시도의 29회는 완료된 두 부팅의 216회와 합치지 않는다. 커널 비교의 warmup·reference 실행도 정식 180회에 포함하지 않는다.

## 지표 정의

- **복구 지연:** affinity 확대 시작부터 네 CPU에 분산된 관측 상태가 50ms 유지되는 구간의 시작점까지. 확인용 50ms는 지연에 더하지 않는다. CPU 샘플에 기반하며 매 순간의 동시 CPU 점유를 직접 추적한 값은 아니다.
- **200ms 조건:** `recovery-200`이라는 조건명이다. 커널 비교의 실제 hold는 136·143·166·184·190·191·250·257ms다.
- **835ms 조건:** 내부 조건명은 `recovery-800`이지만 실제 hold는 835ms다.
- **관측 최댓값:** 그 실험 표본에서 관측한 최대 지연이다. p99, 신뢰구간, 최악시간 상한이 아니다.
- **pinned-256 VM CPU 시간:** Windows 호스트에서 측정한 VM 프로세스의 CPU 시간 중앙값이다. 벽시계 실행시간, CPU 사용률, 실제 주파수나 소비전력이 아니다.

그래프는 0부터 시작하는 선형 축과 원래 단위를 사용한다. 서로 다른 지표를 한 점수로 합치지 않는다. 공개 요약에 분산이나 신뢰구간이 없으므로 오차막대를 만들지 않았다. v22는 원문 표의 소수 둘째 자리 정밀도, JSON이 있는 비교는 원래 값을 읽어 표시한다.

README의 CPU 시간 증감률은 원문에 기록된 **(반복별 짝비교 비율의 중앙값 − 1) × 100**으로 계산한 변화율이다. 그래프의 집계 중앙값끼리 나눠 다시 구한 비율과는 다를 수 있다.

## 결과의 범위

- v18 커널의 결과는 이 VM과 고정 호스트 정책에서 affinity 제한 해제 후 복구 지연이 줄었음을 보여준다. 일반 작업의 모든 실행시간이 단축됐다는 뜻은 아니다.
- 원본 커널은 보관된 프로젝트 기준 이미지이며, 이번 비교에서 upstream을 새로 빌드한 이미지는 아니다.
- v22는 재부팅에서 pinned-256 CPU 비용 기준을 통과하지 못했다.
- v23은 각 부팅의 대조 조건과 비교해 두 부팅 모두 사전 기준을 통과했다. 범용 환경에서의 최적 설정을 보장하지 않는다.
- v24는 v23 대비 추가 개선 기준에 미달했다. 추가 채택과 재부팅 재현을 진행하지 않았으며 주파수·에너지도 측정하지 않았다.

세부 조건은 [커널 비교 프로토콜](../experiments/fixed-host-kernel-ab-20261108/protocol.json), [v22 결과](../versions/v22/RESULTS.md), [v23 결과](../versions/v23/RESULTS.md), [v24 결과](../versions/v24/RESULTS.md)를 따른다.

## 그래프 재생성

저장소 루트에서 실행한다. Matplotlib과 한글 폰트가 필요하다.

```shell
python -m pip install matplotlib==3.10.8
python tools/plot_results.py
```

[생성 스크립트](../tools/plot_results.py)는 위 입력 파일을 읽어 `docs/images/`에 PNG와 SVG를 만든다. README는 PNG로 표시하고 SVG 원본으로 연결한다. 커널 소스·패치·실험 집계값은 변경하지 않는다.
